# Demo clips

Two short clips from the public COUGHVID dataset (Zenodo 4048312, CC BY 4.0),
used by the "Try a sample" buttons.

- `normal.webm` — UUID `14ad2345-dc79-4f0a-981d-8c2f4fc5abef`, self-reported healthy.
- `atypical.webm` — UUID `3ee38361-329e-4927-a373-ae0f22a15f40`, self-reported symptomatic.
- `upload_validation.webm` — UUID `e2f626cc-7a53-47ed-b79b-ee97dbfa1e5b`, self-reported symptomatic, used to exercise the file-upload path in `scripts/capture_screenshots.py`.

These clips are part of the balanced evaluation subset. The demo labels are not
clinical ground truth; they are dataset labels used to exercise the UI.
